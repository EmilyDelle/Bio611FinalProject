The first file is a csv file with the data directly downloaded from Dryad from the Albuquerque et.al. paper (Citation: Albuquerque N, Resende B. Dogs functionally respond to and use emotional information from human expressions. Evolutionary Human Sciences. 2023;5:e2. doi:10.1017/ehs.2022.57)
The second file is a csv file with the supplemental data also from the Albuquerque et. al. paper. The data was download from Dryad as a word document with this data table and some more information on the study. I copyed the data into an excel file saved it as a csv file for use in R.
The third file is a R markdown file with all the code I used to combine the two data files, manipulate, and analyse the data for purpose of answering the questions for my Bio 611 final project regarding exploring the patterns of how dogs can response to audio and visual emotional cues.
